# Firing Reports

Original procedural sound effects for this project, generated by
`FieldAudio.firearm` in `scripts/audio.gd`. No external recordings or sound packs
are used. The six mono, 44.1 kHz, 16-bit WAV files are baked assets so firing and
scene changes do not perform audio synthesis.

- `musket0` through `musket2`: one shared crack/body/reflection set for infantry
  firearms and mounted or dismounted cavalry carbines.
- `cannon0` through `cannon2`: low-frequency pressure report, noisy body, and a
  longer rolling decay, with the sharp upper frequencies reduced.

Regenerate after changing the generator, then import with Godot:

```text
godot --headless --path . --script res://tests/firing_audio.gd -- --bake
godot --headless --editor --path . --import --quit
```

Run `tests/firing_audio.gd` headlessly for waveform/event checks. Run it without
`--headless`, with `-- --playback`, to exercise native playback, overlapping
reports, mute, limiting and cleanup. The overlap stress test mutes its own mix
bus while measuring captured output; it does not change the Master bus.
